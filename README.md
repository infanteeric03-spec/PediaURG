# PediaURG · Cards Medicación Urgente

Calculadora de dosis pediátricas urgentes por peso (Servicio URG-PED, Hospital Universitario San Agustín). PWA instalable, sin dependencias ni build: `index.html` + `sw.js` + `manifest.webmanifest` + iconos.

Categorías: Fármacos, Maniobras, Perfusiones y Patologías (crisis asmática — AEPap; laringitis aguda — SEUP 2024).

Uso como apoyo a la decisión clínica: verificar siempre las dosis con las fuentes originales.

Instalación / publicación: ver `LEEME-instalacion.md`. Con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz) queda en `https://infanteeric03-spec.github.io/PediaURG/`.
